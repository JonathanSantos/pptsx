## M16-5 — `pptsx lint` e codemod
- `pptsx lint <deck> [--fix] [--json] [--size …]` (`src/lint/`). Uma tabela só de aliases (`aliases.ts`, a do apêndice do guia) para o aviso e para o conserto.
- **Detecção sem parser:** o resolve ganhou um gancho opcional `ResolveEnv.observe(kind, path, propsCruas)`; o lint vê as props de cada primitiva com o path exato (componentes como `Bullets size` nunca passam por ali). Regras: `structure` (ResolveError vira achado `error`), `legacy-prop` (com a troca sugerida), `css-not-emitted`, `keynote-line-height` (numérico ≥ 1.5), `grid-fr` (`fr` fora de `minmax(0, …)`), `off-theme-color` (só com tema). Achados iguais em todos os tamanhos saem uma vez (sem `size`); irmãos com a mesma mensagem são agrupados como os diagnósticos (`Box[0..3]`, ×N). Saída texto ou `--json`; exit 1 com error/warning.
- **Codemod (`--fix`):** edições de texto nas posições do AST (formatação do autor intacta), só em tags importadas de `'pptsx'` (respeita `Box as Caixa`). Troca só de nome vale para qualquer valor (inclusive responsivo); troca de valor (`align`, `justify`, `direction`, `italic`, `background`, `stroke`) só com literal — o resto vira aviso com a linha. Conflito (o elemento já tem a prop CSS) também é aviso. Para os frames não mudarem: `stroke`/`strokeWidth` → `outline` (não ocupa espaço, como o stroke antigo; `border` ocuparia).
- **Diferença do plano:** o TypeScript do projeto é o 7, sem `ts.transform`/API em JS. O `--fix` carrega a API de `typescript` (até a 6) ou do alias `typescript-api` (devDependency aqui) e explica a instalação se nenhum existir; a detecção (`pptsx lint` sem `--fix`) não precisa dela.
- Testes: `tests/lint/codemod.test.ts` (17 aliases, renomear com expressão/responsivo, componentes e tags de outro módulo intactos, nome local do import, avisos com linha e conflito, e **`broken-original.tsx` migrado gera a mesma árvore: mesmos paths e frames ±1 pt em 16x9 e 4x3**); `tests/lint/lint.test.tsx` (aliases agrupados, deck CSS limpo, line-height/grid-fr/css-not-emitted, cores fora do tema, estrutura). De ponta a ponta: cópia do `broken-original` → `--fix` faz 8 trocas → novo `lint` sem nada a apontar.
