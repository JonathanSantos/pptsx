## Contrato (M10-0)

### Chart

```tsx
<Chart
  kind="bar"                                  // 'bar' | 'line' | 'pie'
  data={{ categories: ['Q4 25', 'Q1 26', 'Q2 26', 'Q3 26'], series: [{ name: 'Receita', values: [38.2, 41.5, 45.9, 52.4] }] }}
  colors={[color.accent]} legend={false} labels showValues
  grow={1}
/>
```

```ts
export type ChartKind = 'bar' | 'line' | 'pie';
export interface ChartData { readonly categories: readonly string[]; readonly series: readonly { readonly name: string; readonly values: readonly number[] }[] }
export interface ChartProps extends FlexItemProps {
  readonly kind: ChartKind;
  readonly data: ChartData;
  readonly colors?: readonly Color[];      // por série (bar/line) ou por categoria (pie); padrão: paleta de DEFAULTS.chart
  readonly legend?: boolean;               // padrão: series.length > 1
  readonly showValues?: boolean;           // rótulos de valor; padrão false
  readonly font?: string; readonly size?: Pt; readonly color?: Color;   // tipografia dos rótulos; padrão DEFAULTS.chart
  readonly title?: string;
}
```
- Layout: folha sem tamanho intrínseco. Precisa de `width`/`height`, `grow` ou `%`; sem nada → `ResolveError("<Chart> precisa de width/height ou grow")`.
- Validação no resolve: `series[i].values.length === categories.length`; `pie` só aceita 1 série; números finitos.
- Emit: `slide.addChart(pptx.ChartType.<kind>, data, { x, y, w, h, chartColors, showLegend, showValue, dataLabelFontSize, catAxisLabelFontSize, valAxisLabelFontSize, showTitle, title })`. `line` com `lineDataSymbol: 'none'`. `pie` com `showPercent: false` por padrão.
- Preview: SVG próprio, sem biblioteca: barras agrupadas por categoria com eixo Y de 0 ao máximo arredondado (nice number), linhas com polyline, pizza com arcos; rótulos com a fonte registrada; legenda abaixo. Objetivo: reconhecer dados e proporções no overview, não fidelidade de pixel. Nenhum diagnóstico de divergência.

### Table

```tsx
<Table
  columns={[{ header: 'Área', width: '40%' }, { header: 'Q2' , align: 'right' }, { header: 'Q3', align: 'right' }, { header: 'Δ', align: 'right' }]}
  rows={[['Varejo', '21,3', '32,0', '+50%'], ['Crédito', '9,8', '10,1', '+3%']]}
  size={14} minSize={10}
  header={{ fill: color.brand, color: color.white, weight: 'bold' }}
  stripe={color.surface} border={color.muted}
/>
```

```ts
export interface TableColumn { readonly header: string; readonly width?: Length; readonly align?: TextAlign }
export interface TableProps extends FlexItemProps, Pick<TextStyleProps, 'font' | 'size' | 'color' | 'lineHeight'> {
  readonly columns: readonly TableColumn[];
  readonly rows: readonly (readonly string[])[];
  readonly header?: { readonly fill?: Color; readonly color?: Color; readonly weight?: FontWeight } | false;  // false = sem linha de cabeçalho
  readonly stripe?: Color;                 // fundo das linhas pares
  readonly border?: Color;                 // cor das bordas internas; ausente = sem borda
  readonly cellPadding?: Pt;               // padrão DEFAULTS.table.cellPadding (4)
  readonly fit?: FitPolicy;                // shrink (padrão) | error ; truncate não se aplica
  readonly minSize?: Pt;
}
export interface PositionedTable extends ResolvedTable, Positioned {
  readonly columnWidths: readonly Pt[];
  readonly rowHeights: readonly Pt[];      // inclui o cabeçalho quando há
  /** Linhas já quebradas por célula, [linha][coluna]. */
  readonly cells: readonly (readonly TextLayout[])[];
}
```
- Larguras: colunas com `width` em pt ou `%` (da largura da tabela) ficam fixas; as demais dividem o resto igualmente. Largura da tabela = frame (vem do flex; sem `width`/`grow`, estica no eixo cruzado como Box).
- Altura: measure func → para cada célula, `measureText` com `maxWidth = colW − 2 × cellPadding`; `rowH = max(cell.height) + 2 × cellPadding`; altura = soma. É a altura intrínseca do nó Yoga.
- Fit: a tabela entra no escopo do shrink como **uma** unidade (um `TextPlan` com `from = size`, `min = minSizeOf`); encolhe quando o próprio frame recortado pelo pai é menor que a altura medida (mesma regra do Text) ou quando alguma célula tem `wordBroken`. Não coube no mínimo → `table-overflow` (error) com linhas visíveis × totais.
- Emit: `slide.addTable(rows, { x, y, w, colW, rowH, fontFace, fontSize: fontSize final, margin: cellPadding, border, fill por linha, align por coluna, valign: 'top', autoPage: false })`. Texto das células com **quebra forçada** (um run por linha calculada) como no Text, para o renderizador não recalcular a altura. `header` vira a primeira linha com `bold`/`fill`/`color`.
- Preview: `<rect>` por célula (stripe/header/border) + `<text>` por linha calculada.

### Diagnóstico novo

| Situação | code | severity | data |
|---|---|---|---|
| Tabela não cabe nem no `minSize` (ou `fit="error"`) | `table-overflow` | error | overflowPt, overflowPct, fromSize, toSize |

## Testes (M10-F) — mínimo

- Resolve: série com tamanho diferente → `ResolveError`; `pie` com 2 séries → erro; linha com menos colunas → erro; `Chart` sem tamanho/grow → erro.
- Layout da tabela: 1 coluna `40%` + 3 livres numa tabela de 600 pt → `[240, 120, 120, 120]`; `rowHeights` = max das células + 2 × padding; célula com texto de 3 linhas define a altura da linha.
- Fit: tabela de 20 linhas num Box de 200 pt → `toSize < fromSize` e, se `minSize` alto, `table-overflow` com `shown/total`.
- Emit: opções do `addTable` (colW em polegadas, rowH, runs por linha) e do `addChart` (tipo, cores sem `#`, legenda); snapshot do XML do gráfico contém `<c:barChart>`.
- Preview: SVG da tabela tem `rows × cols` rects; SVG do gráfico de barras tem `categories × series` rects com altura proporcional ao valor.
