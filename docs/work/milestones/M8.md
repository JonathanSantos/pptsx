## Contrato (M8-0)

### Primitivas inline

```tsx
<Text size={20}>Receita <B>subiu</B> 14% em <Span color="#2F6FED" italic>todas</Span> as regiões.</Text>
```

```ts
export interface SpanProps {
  readonly weight?: FontWeight;
  readonly italic?: boolean;
  readonly color?: Color;
  readonly children?: TextChildren;   // strings, números e outros Span/B/I
}
export const Span: Primitive<'span'>; export const B: Primitive<'span'>; export const I: Primitive<'span'>;
// B = Span com weight 'bold'; I = Span com italic true (definidos em primitives/ como wrappers; kind 'span')
```

- `Span` só pode aparecer dentro de `Text` (ou de outro `Span`); fora → `ResolveError("<B> só pode aparecer dentro de <Text>")`.
- `size`, `font` e `lineHeight` **não** são por run: a linha tem altura única (simplifica medição e calibração). `Span` com essas props não compila.
- `TextChildren` passa a aceitar `SlideElement` cujo `type` é `Span`; o resolve valida.

### Árvore resolvida

```ts
export interface TextRun {
  readonly text: string;
  /** Estilo efetivo do run (herda do Text, sobrescrito pelos Span aninhados). */
  readonly weight: FontWeight;
  readonly italic: boolean;
  readonly color: Color;
}
export interface ResolvedText {
  readonly kind: 'text'; readonly path: string; readonly props: ...;
  /** Texto plano concatenado ('\n' separa parágrafos) — para diagnósticos e palavras partidas. */
  readonly content: string;
  /** Runs em ordem; a concatenação de `text` é igual a `content`. Sem Span: um run só. */
  readonly runs: readonly TextRun[];
}
```

### Medição

```ts
export interface TextMeasureInput {
  readonly content: string;
  readonly runs: readonly TextRun[];     // NOVO
  readonly style: TextStyle;             // family, size, lineHeight (weight/italic do Text são o padrão dos runs)
  readonly maxWidth: Pt;
  readonly maxLines?: number;
  readonly nowrap?: boolean;             // NOVO
}
export interface LineRun { readonly text: string; readonly run: number /* índice em runs */ }
export interface TextLayout {
  // ... atuais (lines, paragraphs, fontSize, lineHeight, ascent, width, height, wordBroken, truncated, fontMissing, widestSegment)
  /** NOVO: as mesmas linhas de `lines`, cada uma dividida por run. join('') de cada linha === lines[i]. */
  readonly lineRuns: readonly (readonly LineRun[])[];
}
```

Regras:
- Largura de um segmento = soma das larguras de suas partes, cada parte medida com a face do seu run (regular/bold/itálico). Kerning não cruza fronteira de run.
- Ponto de quebra continua sendo espaço (U+0020 e outros `\s` **exceto U+00A0**) e depois de `-`/`/`. **U+00A0 é glue**: faz parte do segmento, medido como espaço. `brokenWordsOf` usa a mesma regra.
- `nowrap`: cada parágrafo é uma linha só; `wordBroken` fica `false`; `width` = linha mais larga mesmo que passe de `maxWidth`. O fit trata `width > frame.width + epsilon` como gatilho de shrink (mesmo peso do `wordBroken`) e, se persistir, `text-overflow` com `data.axis: 'width'` e mensagem de largura (`"Texto com nowrap tem 212 pt de largura numa área de 180 pt..."`).
- `lineHeight`/`ascent` da linha vêm da face do Text (regular ou bold conforme `weight`); runs em outra face não mudam a altura (métricas verticais da Liberation/Arial são iguais entre faces; documentar que fontes com métricas diferentes por face podem desviar 1–2 %).
- `fontMissing` é true se **qualquer** face usada pelos runs faltar.

### Layout

- `Align` ganha `'baseline'` (em `align` e `alignSelf`). Só vale em `row`; em `column` é tratado como `start`.
- Baseline de cada nó: Text → `text.ascent` (1ª linha); Box → baseline do 1º filho em fluxo (Yoga faz isso sozinho quando o filho tem baseline func); Image/Shape → `frame.height` (base).
- `nowrap` num Text em `row`: `minWidth` = largura da linha mais larga, para o Yoga não espremer abaixo disso.

### Fontes

```ts
export interface FontFace {
  readonly family: string;
  readonly weight: FontWeight;
  readonly italic?: boolean;
  /** Caminho .ttf/.otf. Ausente → procurar no sistema (M8-D). */
  readonly file?: string;
}
export interface RenderOptions { /* ... */ readonly embedFonts?: boolean /* padrão false */ }
```

Resolver (M8-D), `src/fonts/system.ts`:
- Diretórios por plataforma: macOS `/System/Library/Fonts`, `/System/Library/Fonts/Supplemental`, `/Library/Fonts`, `~/Library/Fonts`; Linux `/usr/share/fonts`, `/usr/local/share/fonts`, `~/.fonts`, `~/.local/share/fonts`; Windows `%WINDIR%\Fonts`, `%LOCALAPPDATA%\Microsoft\Windows\Fonts`. Lista injetável (para teste).
- Varre `.ttf`/`.otf`/`.ttc` uma vez por processo (cache em memória por caminho + mtime), abre com fontkit, indexa por `familyName` normalizado (minúsculas, sem espaços duplos), peso via `OS/2.usWeightClass` (≥ 600 = bold) e itálico via `OS/2.fsSelection` bit 0 ou `head.macStyle` bit 1; `.ttc` indexa cada face.
- `FontFace` sem `file` que não é encontrada → `font-missing` em todo Text que a usa (sem fallback silencioso), já na criação do registro (lista no resultado: `RenderResult.fontsMissing?: string[]`) **e** por nó.
- O par Liberation→Arial continua sendo o padrão quando `fonts` não é informado.

Embed (M8-D, conforme M8-S): pós-processamento do zip em `src/emit/embed.ts`: adiciona `ppt/fonts/fontN.fntdata` por face usada, `<p:embeddedFontLst>` em `presentation.xml`, relacionamentos e content types. Se o spike mostrar que PowerPoint exige obfuscação, implementar o algoritmo do ECMA-376 (XOR dos 32 primeiros bytes com o GUID); se mostrar que o Keynote ignora embed, anotar e seguir.

### Emissão e preview

- Emit: para cada linha, um `<a:r>` por `LineRun`, com `bold`/`italic`/`color` do run; `softBreakBefore` só no 1º run da linha; `breakLine` só no último run da última linha do parágrafo. `lineBreaks: 'auto'` (M7): um run por `TextRun` por parágrafo.
- Preview: `<text>` por linha com um `<tspan>` por run (`font-weight`, `font-style`, `fill`); `xml:space="preserve"` nos tspans.
