## Contrato (M7-0)

### Nome do pacote

Decisão do dono antes da onda. O nome entra em `package.json`, no `jsxImportSource` dos exemplos e do `init`, no `bin` e nas docs. Enquanto não houver decisão, tudo abaixo diz `<pacote>`.

### `src/core/types.ts`

```ts
export interface RenderOptions {
  // ... atuais ...
  /**
   * 'forced' (padrão): cada linha calculada vira <a:br/> (renderizador não requebra; calibração 34/34).
   * 'auto': só parágrafos; o renderizador quebra com a própria métrica (texto mais editável, pode divergir 1 linha).
   */
  readonly lineBreaks?: 'forced' | 'auto';
  /** Inclui a árvore posicionada no resultado (para ferramentas e previews externos). Padrão false. */
  readonly includePositioned?: boolean;
}

export interface RenderResult {
  // ... atuais ...
  readonly positioned?: PositionedDeck;
}
```

`DEFAULTS.lineBreaks = 'forced'`.

### `src/core/dispatch.ts` (novo, orquestrador)

```ts
/** Tabela por `kind` sem cast espalhado: o tipo da tabela garante a coerência. */
export const dispatch = <N extends { readonly kind: string }, R, Extra extends unknown[]>(
  table: { readonly [K in N['kind']]: (node: Extract<N, { kind: K }>, ...extra: Extra) => R },
  node: N,
  ...extra: Extra
): R => (table[node.kind as N['kind']] as (node: N, ...extra: Extra) => R)(node, ...extra);
```

M7-D troca os `as never`/`as Builder<ResolvedNode>` de `layout/tree.ts`, `layout/read.ts`, `emit/emitters.ts` e `preview/slide.ts` por `dispatch(...)`. Um único cast, num único lugar.

### Build (M7-A)

- `tsconfig.build.json`: `extends ./tsconfig.json`, `include: ["src"]`, `noEmit: false`, `outDir: dist`, `declaration: true`, `rewriteRelativeImportExtensions: true` (TS ≥ 5.7 reescreve `./x.ts` → `./x.js` na saída). Sem `paths`.
- `package.json`:
  ```json
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": { "types": "./dist/index.d.ts", "import": "./dist/index.js" },
    "./jsx-runtime": { "types": "./dist/jsx/jsx-runtime.d.ts", "import": "./dist/jsx/jsx-runtime.js" },
    "./jsx-dev-runtime": { "types": "./dist/jsx/jsx-dev-runtime.d.ts", "import": "./dist/jsx/jsx-dev-runtime.js" }
  },
  "bin": { "<pacote>": "./bin/<pacote>.mjs" },
  "files": ["dist", "bin", "fonts", "README.md"],
  "scripts": { "build": "tsc -p tsconfig.build.json", "prepack": "npm run build", "test:package": "vitest run tests/package" }
  ```
  `tsx` sai de `devDependencies` e vira `dependencies` (a CLI precisa dele para carregar o deck `.tsx` do usuário).
- `bin/<pacote>.mjs`: registra `tsx/esm/api` **só para o deck e a config do usuário** e importa `../dist/cli.js`. Mantém o fallback do tsconfig do pacote quando o cwd não tem um (hoje já existe), mas o tsconfig de fallback passa a ser um `tsconfig.deck.json` mínimo no pacote (`jsx: react-jsx`, `jsxImportSource: <pacote>`), sem `paths`.
- `src/fonts.ts`: caminho das fontes continua por `import.meta.url` (`../fonts/` vale tanto em `src/` quanto em `dist/`).
- Dentro deste repo, `examples/` e `tests/` continuam resolvendo `<pacote>` pelo `paths` do `tsconfig.json` e pelo alias do vitest; nada muda para quem desenvolve a engine.

### CLI (M7-B)

```
<pacote> build <deck.tsx> [flags atuais] [--line-breaks forced|auto] [--watch]
<pacote> init [dir]            # cria deck.tsx, tsconfig.json, <pacote>.config.ts, assets/ e um .gitignore com dist/
```

- `init`: recusa se `deck.tsx` já existe no diretório (sem `--force`). O `tsconfig.json` gerado tem `jsx: react-jsx`, `jsxImportSource: <pacote>`, `module: NodeNext`, `strict: true`. O `deck.tsx` gerado é um deck de 2 slides só com primitivas (sem depender de `examples/`). Imprime os próximos comandos.
- `--watch`: observa o diretório do deck (recursivo, `fs.watch`), a config e os `src` de imagens referenciados; debounce 150 ms; a cada mudança refaz o build e imprime o resumo com timestamp; erros de sintaxe não derrubam o watch. O `import()` do deck usa `?v=<mtime>` para furar o cache de módulos ESM. `--watch` com `--json` imprime um JSON por build, um por linha (NDJSON). Ctrl-C sai com 0. A função de observar é injetável (`watch: (paths, onChange) => () => void`) para o tester.
- Config: `defineConfig({ ..., lineBreaks? })`. Flag vence config.

### Emissor (M7-C)

- `lineBreaks: 'auto'`: um `<a:p>` por parágrafo do autor, texto inteiro num run, sem `softBreakBefore`; `wrap: true`; demais opções iguais. A caixa continua com o frame calculado. A estratégia entra em `EmitContext` como `lineBreaks`, vinda de `RenderOptions`.
- `render` com `includePositioned: true` devolve `positioned` (a mesma árvore que foi ao emissor, depois do fit).

### Sanitize (M7-D)

Manter a abordagem por regex, mas:
- extrair o parser de parágrafos para uma função pura `paragraphsOf(xml): string[]` e cobrir com um **teste de propriedade** (fast-check ou gerador próprio): para qualquer sequência de runs com e sem `<a:br/>`, a saída tem exatamente um `<a:pPr>` por `<a:p>` e o texto de `<a:t>` é preservado na ordem;
- validar o XML resultante com um parser (`fast-xml-parser` em devDependency, só no teste) para garantir que continua bem formado.

### `vitest.config.ts` (M7-D)

Remover o bloco `esbuild`; manter `oxc: { jsx: { runtime: 'automatic', importSource: '<pacote>' } }` (ou a chave equivalente da versão instalada). O aviso "Both esbuild and oxc options were set" some.

## Testes (M7-E) — mínimo

- `tests/package/`: `npm pack` para um diretório temporário, `npm install <tarball>` num projeto vazio, `init`, `build deck.tsx --preview none`, exit 0 e `.pptx` com `ppt/slides/slide1.xml`. Marcado como lento (timeout 120 s) e rodado só por `npm run test:package` (não entra no `npm test`).
- `init` em diretório com `deck.tsx` → erro; com `--force` sobrescreve.
- `--watch` com `watch` injetado: dois eventos em 50 ms → um build (debounce); erro de sintaxe → `{ error }` em NDJSON e o watch continua.
- `--line-breaks auto`: o XML do slide não contém `<a:br/>`; `forced` contém.
- `includePositioned`: `positioned.slides.length === n` e frames em pt.
- `dispatch` com tabela incompleta não compila (teste de tipo com `// @ts-expect-error`).
- Sanitize: propriedade + XML bem formado.
