## Contrato da CLI (M5-A)

```
tsx-slides build <deck.tsx> [--size 16x9,4x3,10x7.5in] [--out dist/] [--debug] [--json]
                            [--preview native|none] [--preview-width 1280] [--lang pt-BR]
```
- `--json`: stdout recebe **só** o JSON `{ files: string[], diagnostics: Diagnostic[] }` (para agentes); nada de resumo.
- Sem `--json`: lista de arquivos + resumo legível (já existe).
- Exit code: 1 se houver qualquer `error` **ou** falha (deck inválido, ResolveError…); 0 caso contrário. Erros de execução com `--json` saem como `{ error: message }` em stdout.
- `tsx-slides.config.ts` opcional, procurado no diretório atual: `export default defineConfig({ fonts?, sizes?, lang?, textSafety? })`. Flags da CLI vencem a config. `defineConfig` = identidade tipada exportada por `tsx-slides`.

## Contrato dos componentes de exemplo (M5-B implementa, M5-C documenta)

`examples/tokens.ts`:

```ts
           positive: '#1E9E6A', negative: '#D64545' },
  font: { display: 44, h1: 32, h2: 24, body: 20, small: 14, caption: 11 },
  space: { page: 40, gap: 20, tight: 10 },

```

`examples/layouts/` (cada um devolve um `<Slide>`):
| Componente | Props | Estrutura |
|---|---|---|
| `CoverLayout` | `title: string; subtitle?: string; caption?: string; ctx?: DeckContext` | fundo `brand`, círculo decorativo absoluto (diâmetro = 0.9 × `ctx.height`, sup. dir.), bloco de título ancorado embaixo à esquerda: título `display` bold branco (shrink, minSize 32), subtítulo `h2` (truncate, maxLines 2); `caption` pequena no topo |
| `ContentLayout` | `title: string; justify?: 'start' \| 'center'; children` | fundo branco, padding `page`, header (barra `accent` + título `h1` bold), corpo `Box grow={1} justify={justify}` com os children (padrão `'start'`) |
| `ClosingLayout` | `title: string; subtitle?: string; contact?: string; ctx?: DeckContext` | fundo `brand`, texto centralizado (subtítulo com 80% da largura), círculo decorativo (diâmetro = 0.75 × `ctx.height`, inf. esq.) fora da área do texto |

Sem `ctx`, os layouts usam a altura do 16:9 (405 pt) para o círculo; largura = altura em pt mantém o círculo em qualquer proporção.

`examples/components/`:
| Componente | Props | Comportamento |
|---|---|---|
| `Bullets` | `items: readonly string[]; size?: number` (padrão `font.body`); `gap?: number` (padrão `0.7 × size`) | coluna; cada item = row com marcador elipse `accent` 8×8 + Text grow shrink (minSize 14) |
| `TwoColumn` | `left: Child; right: Child; stacked?: boolean; ratio?: number` (fração da esquerda, padrão 0.5) | row com gap, colunas alinhadas ao topo; `stacked` → column (usar com `ctx.aspect < 1.5`) |
| `KpiCard` | `label: string; value: string; delta?: string; trend?: 'up' \| 'down'; sentiment?: 'positive' \| 'negative' \| 'neutral'; size?: 'sm' \| 'md' \| 'lg'` | Box `surface` radius 8 padding; valor grande bold, label muted, delta. `trend` → seta (▲/▼); `sentiment` → cor (`positive`/`negative`/`muted`); sem `sentiment`: up → positive, down → negative, sem trend → neutral. `size` (padrão `md` = padding 20, label 14, valor 44): `sm` = 14/12/32, `lg` = 20/16/56 |
| `KpiRow` | `items: readonly KpiCardProps[]; size?: 'sm' \| 'md' \| 'lg'` | row com gap, cada card `grow={1}`; `size` repassado a todos (o do item vence) |

`examples/demo.tsx` (5 slides, `defineDeck((ctx) => …)`): capa · título + bullets · duas colunas com imagem (`stacked={ctx.aspect < 1.5}`) · linha de KPI cards · encerramento. Sem nenhum diagnóstico `error` em 16x9 e 4x3.
