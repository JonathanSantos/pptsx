## Contrato da CLI (M5-A)

```
tsx-slides build <deck.tsx> [--size 16x9,4x3,10x7.5in] [--out dist/] [--debug] [--json]
                            [--preview native|none] [--preview-width 1280] [--lang pt-BR]
```
- `--json`: stdout recebe **só** o JSON `{ files: string[], diagnostics: Diagnostic[] }` (para agentes); nada de resumo.
- Sem `--json`: lista de arquivos + resumo legível (já existe).
- Exit code: 1 se houver qualquer `error` **ou** falha (deck inválido, ResolveError…); 0 caso contrário. Erros de execução com `--json` saem como `{ error: message }` em stdout.
- `tsx-slides.config.ts` opcional, procurado no diretório atual: `export default defineConfig({ fonts?, sizes?, lang?, textSafety? })`. Flags da CLI vencem a config. `defineConfig` = identidade tipada exportada por `tsx-slides`.

## Contrato dos componentes de exemplo (M5-B implementa, M5-C documenta)

`examples/tokens.ts`:
```ts
export const tokens = {
  color: { brand: '#1B2A4A', brandDark: '#101B33', accent: '#2F6FED', accentSoft: '#E8EEFC',
           ink: '#1B2A4A', muted: '#5B6680', surface: '#F4F6FA', white: '#FFFFFF',
           positive: '#1E9E6A', negative: '#D64545' },
  font: { display: 44, h1: 32, h2: 24, body: 20, small: 14, caption: 11 },
  space: { page: 40, gap: 20, tight: 10 },
} as const;
```

`examples/layouts/` (cada um devolve um `<Slide>`):
| Componente | Props | Estrutura |
|---|---|---|
| `CoverLayout` | `title: string; subtitle?: string` | fundo `brand`, elipse decorativa absoluta, título `display` bold branco (shrink, minSize 32), subtítulo `h2` (truncate, maxLines 2) |
| `ContentLayout` | `title: string; children` | fundo branco, padding `page`, header (barra `accent` + título `h1` bold), corpo `Box grow={1}` com os children |
| `ClosingLayout` | `title: string; subtitle?: string; contact?: string` | fundo `brand`, texto centralizado |

`examples/components/`:
| Componente | Props | Comportamento |
|---|---|---|
| `Bullets` | `items: readonly string[]; size?: number` (padrão `font.body`) | coluna; cada item = row com marcador elipse `accent` 8×8 + Text grow shrink (minSize 14) |
| `TwoColumn` | `left: Child; right: Child; stacked?: boolean; ratio?: number` (fração da esquerda, padrão 0.5) | row com gap; `stacked` → column (usar com `ctx.aspect < 1.5`) |
| `KpiCard` | `label: string; value: string; delta?: string; trend?: 'up' \| 'down'` | Box `surface` radius 8 padding; valor grande bold, label `small` muted, delta colorido por trend |
| `KpiRow` | `items: readonly KpiCardProps[]` | row com gap, cada card `grow={1}` |

`examples/demo.tsx` (5 slides, `defineDeck((ctx) => …)`): capa · título + bullets · duas colunas com imagem (`stacked={ctx.aspect < 1.5}`) · linha de KPI cards · encerramento. Sem nenhum diagnóstico `error` em 16x9 e 4x3.
